# Search

The search bar in the main Room view lets you quickly find documents and links anywhere in the Room without having to manually navigate through sections and subsections.

---

## Using the Search Bar

1. Click the **search bar** in the toolbar at the top of the Room view
2. Start typing — results appear automatically as you type (after a brief pause)
3. Results are grouped into two sections:
   - **Documents** — matching document names
   - **Links** — matching link names

---

## Navigating to a Result

Click any result in the dropdown list. The application will:
1. Automatically expand the section and subsection that contain the matching item
2. Scroll the page to bring the matching row into view
3. Briefly highlight (pulse) the matching document or link row so it's easy to spot

---

## Clearing the Search

Click the **× button** inside the search bar (it appears once you've typed something) to clear the search input and close the results dropdown.

---

## Search Scope

Search covers:
- Document names across all sections and subsections
- Link names across all sections and subsections

Search does **not** currently cover:
- Section or subsection names
- Document contents (even though documents are indexed for future content search)
- Link descriptions or URLs
- Items that are in the Trash Bin (use the [Trash Bin](./trash-bin.md) page to browse trashed items)
