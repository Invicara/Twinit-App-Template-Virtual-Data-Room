# User Guide

Welcome to the Virtual Data Room (VDR). This guide explains how to use the application as an end user — no technical background required.

## Contents

- [Getting Started](./getting-started.md) — Signing in and selecting your Room
- [Access & Roles](./access-and-roles.md) — Understanding Room Admin, Section Admin, Contributor, and Viewer roles
- [Managing Sections](./managing-sections.md) — Create, edit, and remove top-level sections
- [Managing Subsections](./managing-subsections.md) — Create, edit, and navigate subsections
- [Documents](./documents.md) — Upload, view, version, and manage document status
- [Links](./links.md) — Add, edit, and track external URL references
- [Search](./search.md) — Find documents and links across the entire Room
- [Trash Bin](./trash-bin.md) — Restore or permanently delete trashed items (Room Admin only)
- [Manage Users](./manage-users.md) — Invite users and view section group membership (Room Admin only)
