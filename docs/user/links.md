# Links

Links are external URL references stored inside a subsection alongside documents. Use them to point to relevant web pages, external systems, or other online resources that relate to the subsection's content.

---

## Adding a Link

> **Role required:** Section Contributor, Section Admin, or Room Admin. Section Viewers do not see the link creation form.

1. Expand the subsection you want to add a link to (click the chevron on the subsection row)
2. Scroll down past the document area to the **Links** section
3. Fill in the **Add Link** form:
   - **Name** *(required)* — a short display name for the link (e.g. "Project Homepage")
   - **Description** *(optional)* — additional context
   - **URL** *(required)* — must begin with `http://` or `https://`
4. Click **Add Link**

The link will appear in the link table immediately below the form.

---

## Opening a Link

Click the **external link icon** (arrow pointing out of a box) on a link row. The URL opens in a new browser tab.

---

## Link Status

Links support the same status values as documents:

| Status | Meaning |
|---|---|
| For Review | Awaiting review |
| Approved | Reviewed and approved |
| Rejected | Reviewed and rejected |

### Changing a link's status

> **Role required:** Section Admin or Room Admin. Section Contributors and Viewers see a read-only status badge with no dropdown.

1. Click the current status pill on the link row
2. Select the new status from the dropdown
3. Optionally enter a note in the **Status Note** dialog
4. Confirm

Status changes are recorded in the link's history log.

---

## Editing a Link

> **Role required:** Section Contributor, Section Admin, or Room Admin. Section Viewers see a dimmed, non-clickable edit icon.

1. Click the **pencil (edit) icon** on the link row
2. In the dialog, update the name, description, and/or URL
3. Save your changes

---

## Viewing Link History

1. Click the **clock (history) icon** on the link row
2. The Link Logs dialog shows a chronological list of all status changes, including timestamps and any notes that were added

---

## Moving a Link to Trash

> **Role required:** Section Contributor, Section Admin, or Room Admin. Section Viewers see a dimmed, non-clickable trash icon.

1. Click the **trash icon** on the link row
2. Confirm in the dialog

The link moves to the Trash Bin. See [Trash Bin](./trash-bin.md) for restore and permanent delete options.
