# Trash Bin

The Trash Bin is a holding area for items you have moved to trash. Nothing is permanently removed from the system until you explicitly delete it from the Trash Bin.

> **Role required:** Room Admin only. Non-admin users are automatically redirected to the main Room view if they attempt to access this page.

---

## Opening the Trash Bin

From the main Room view, click the **hamburger menu (☰)** in the toolbar and select **View Trash Bin**.

> **Note:** The hamburger menu is only visible to Room Admins.

Click **← Back to Room** at the top of the Trash Bin page to return to the main view.

---

## What's in the Trash Bin

The Trash Bin groups trashed items into four separate tables:

| Table | Contains |
|---|---|
| **Sections** | Sections that have been trashed |
| **Subsections** | Subsections that have been trashed |
| **Documents** | Documents that have been trashed |
| **Links** | Links that have been trashed |

Each table shows a "No … in trash" message if there is nothing trashed in that category.

---

## Restoring an Item

To move an item back to its original location in the Room:

1. Find the item in the appropriate table
2. Click the **restore (circular arrow) icon** on the item's row
3. A spinner indicates the restore is in progress

The item will disappear from the Trash Bin and reappear in the Room in its original section and subsection.

---

## Permanently Deleting an Item

> **This action cannot be undone.**

To permanently remove an item:

1. Find the item in the appropriate table
2. Click the **trash (delete) icon** on the item's row
3. A confirmation dialog will appear, reminding you that the action is permanent
4. Click **Delete Permanently** to confirm

### Cascade deletion

Permanently deleting a parent item also deletes all of its children:

| Item deleted | Also permanently deletes |
|---|---|
| A **Section** | All of its subsections, and all documents and links in those subsections |
| A **Subsection** | All documents and links inside it |
| A **Document** | Only that document |
| A **Link** | Only that link |

---

## Viewing Trashed Documents

In the Documents table of the Trash Bin, you can:
- **View** a document using the inline document viewer (click the view icon)
- **Download** a document (download icon)
- See its current **status** and **version number**

---

## Viewing Trashed Link History

In the Links table of the Trash Bin, you can view a trashed link's status change history by clicking the **clock (history) icon** on the link row. This opens the Link Logs dialog showing all past status changes.
